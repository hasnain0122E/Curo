# CURO — Setup Guide 
## Prerequisites - Flutter SDK >= 3.19.0 - Dart >= 3.3.0 - VS Code with Flutter + Dart extensions - Firebase CLI: npm install -g firebase-tools 
## Steps 
1. Clone: git clone https://github.com/YOUR_USERNAME/curo.git 
2. cd curo && flutter pub get 
3. Add google-services.json to android/app/ 
4. Add GoogleService-Info.plist to ios/Runner/ 
5. flutter run
