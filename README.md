## 📖 Overview

Healthcare services can often be expensive, fragmented, and difficult to access. **CURO** addresses these challenges by providing a centralized healthcare platform designed to make healthcare more accessible and affordable.

The application integrates Artificial Intelligence, cloud technologies, and location-based services to simplify everyday healthcare tasks such as finding nearby laboratories, uploading medical reports, scanning prescriptions, identifying medicines, and securely storing health records.

This project was developed as a university Final Year Project (FYP) using modern Flutter development practices and Firebase services.

# 🔥 Firebase Configuration

Create a Firebase project and enable:

- Firebase Authentication
- Cloud Firestore
- Firebase Analytics
- Crashlytics
- Cloud Messaging

Then place the generated Firebase configuration files:

Android

```
android/app/google-services.json
```

iOS

```
ios/Runner/GoogleService-Info.plist
```
